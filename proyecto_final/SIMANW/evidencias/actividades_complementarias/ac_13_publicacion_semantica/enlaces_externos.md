# Enlaces con recursos externos

## Criterio

Cada categoría del SIMANW se vinculó con una entidad equivalente ampliamente utilizada.

## Enlaces establecidos

| Recurso local        | Recurso externo        |
| -------------------- | ---------------------- |
| categoria_tecnologia | Wikidata Q11016        |
| categoria_economia   | Wikidata Q159810       |
| categoria_ciencia    | Wikidata Q336          |
| categoria_gobierno   | Wikidata Q7188         |
| noticia_1            | Schema.org NewsArticle |

## Tipo de relación

* owl:sameAs
* skos:exactMatch

## Justificación

Permiten interoperabilidad con sistemas externos y reutilización por agentes semánticos.
